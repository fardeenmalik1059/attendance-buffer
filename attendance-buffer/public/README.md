## 📌 Project Overview
**Attendance Buffer** is a full-stack Node.js and Express application designed to help university students track their academic attendance metrics dynamically.

### Key Features:
* **Subject Management:** Add, update, and remove subject records with target attendance thresholds (e.g., 75%).
* **Real-time Metrics:** Displays overall attendance percentage and total classes attended vs. held.
* **Buffer Analysis ("What-If" Calculator):** Calculates how many classes you can safely skip or must attend to clear attendance deficits.
* **Database Integration:** Persistent storage using MongoDB and Mongoose models.
